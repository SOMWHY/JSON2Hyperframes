# __PROJECT__

[English](README.md) | [简体中文](README_zh.md)

> Generated by `j2hf init` — JSON2Hyperframes project

## Quick Start

```bash
# 1. Generate HyperFrames HTML from video-config.json
j2hf generate

# 2. Preview in browser
j2hf preview

# 3. Render to MP4
j2hf render
```

## Project Structure

```
__PROJECT__/
├── video-config.json    edit this to build your video
│                       JSON schema: schemas/video-config.schema.json
├── output/              generated HyperFrames HTML (index.html)
├── videos/              rendered MP4 output
└── README.md
```

## Configuration

Edit `video-config.json` to set:

- **Composition**: resolution, fps, duration, palette
- **Scenes**: each scene has elements (text, image, shape, video, group, icon)
- **Animations**: GSAP-powered tweens per element (from/to/fromTo)
- **Architecture**: `monolithic` (single file) or `modular` (nested compositions)

## Commands

| Command | Description |
|---------|-------------|
| `j2hf generate` | Read config → write HyperFrames HTML to `output/` |
| `j2hf preview` | Start preview server on `output/` |
| `j2hf render` | Render MP4 via hyperframes, saved to `videos/` |
| `j2hf init <name>` | Create a new project |
| `j2hf generate --config=path.json` | Use a custom config path |

## Assets

Place media files (images, videos, audio) in the project root or subdirectories.
Reference them in `video-config.json` by relative path.
